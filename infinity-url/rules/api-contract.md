# API contract

The contract is in `docs/10-api.md`. This rule is the part an agent must not
improvise.

## Errors

RFC 9457, `application/problem+json`, always with a stable `code`:

```json
{
  "type": "https://api.url.infinityproject.fr/problems/slug-taken",
  "title": "Slug already taken",
  "status": 409,
  "detail": "The slug 'promo' is already used on this domain.",
  "code": "slug_taken",
  "errors": { "slug": ["This slug is already used on this domain."] }
}
```

- Never translate an error message server-side. The server returns a code; the
  front translates.
- `404` also for a resource owned by another workspace: never reveal existence.
- `410` for a deleted or expired link. `403` only for abuse-blocked links.

## Pagination

Cursor, never offset. `?limit=` (default 20, max 100) and `?cursor=`, response
shape `{ "data": [], "next_cursor": null, "has_more": false }`.

## Authorization

- **Every authenticated route declares at least one ability.** A route without
  one is a bug, and an architecture test enforces it.
- Abilities: `me:read`, `links:read`, `links:write`, `stats:read`,
  `domains:read`, `domains:write`, `tokens:read`, `tokens:write`.
- No API token receives `*`. Only the dashboard's access token does.
- A `refresh` token carries only `refresh`: it can reach no endpoint.

## Redirect semantics

```http
HTTP/1.1 302 Found
Location: https://example.com/page
Cache-Control: no-store
Referrer-Policy: no-referrer
X-Robots-Tag: noindex
```

`302`, never `301` (a permanent redirect cannot be edited). `no-store`, or the
browser stops calling and clicks are lost. No body. `HEAD` is accepted and
**not counted**.

## Versioning

`/v1` in the path. Additive changes only. A breaking change opens `/v2` with
twelve months of overlap. Deprecation through `Deprecation` and `Sunset`.

## OpenAPI

Generated by `dedoc/scramble`, served at `/openapi.json` and `/docs`. A test
fails if a public route is missing from the spec, or if the web types are stale.
